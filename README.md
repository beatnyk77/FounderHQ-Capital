# FounderHQ Capital

Founder, investing & acquisition simulation game. Phase 1 MVP.

## Play

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## MVP Features

- **Accelerated real-time** — 1 game week every 2.5 minutes
- **Living economy** — bull / neutral / bear macro regimes
- **Weekly pulse** — opportunity, threat, reward, uncertainty events
- **Capital raising** — accept or decline term sheets
- **M&A** — acquire targets to grow product & market share
- **News wire** — emergent headlines from simulation events
- **Leaderboard** — local high scores on exit

## Stack

Next.js 15 · TypeScript · Tailwind CSS · Zustand
